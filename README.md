# 🌤️ Weather Dashboard

A responsive weather dashboard that displays real-time weather information for any city using JavaScript and a REST API.

**Live Demo:** https://koda-bhavani.github.io/weather-dashboard/

### ✨ Features
- 🔍 Search weather by city name
- 🌡️ Shows Temperature, Humidity, Wind Speed, Weather Condition
- 📅 5-Day Weather Forecast
- 📱 Fully Responsive - Works on Mobile & Desktop
- ⚡ Fast & Clean UI
- 🌍 Real-time data from API

### 🛠️ Built With
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **REST API - OpenWeatherMap API**
- **GitHub Pages** for hosting

### 📁 Files
weather-dashboard/
├── index.html   # Main HTML
├── style.css    # Styling
├── script.js    # API logic & JavaScript
└── README.md

### 🚀 How It Works
1. User enters a city name
2. JavaScript fetches data from OpenWeatherMap API
3. Displays current weather & forecast on the dashboard

### 🔑 API Used
- OpenWeatherMap API - https://openweathermap.org/api
